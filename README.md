# SQL-versus-Pandas
Mini project to show various SQL style operations with pandas (a python library).

# Aim
The aim of this project is to demonstrate the equivalence between SQL queries and pandas data operations given the background I have in SQL.

# Tech Stack
SQL <br>
Python (with Pandas) <br>
Jupyter Notebooks <br>

# Dataset 
- Heart Disease:
https://www.kaggle.com/datasets/oktayrdeki/heart-disease/data) <br>
- Heart Attack Risk Prediction:
https://www.kaggle.com/datasets/iamsouravbanerjee/heart-attack-prediction-dataset 


## Covered Topics
| SQL Concept | pandas Equivalent |
|-------------|-------------------|
| `SELECT`    | `df[]`            |
| `LIMIT`     | `head()`          |
| `WHERE`     | Boolean filtering |
| `ORDER BY`  | `sort_values()`   |
| `JOIN`      | `merge()`         |
